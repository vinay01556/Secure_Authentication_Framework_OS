# Secure_Authentication_Framework_OS
Project Overview

This project focuses on designing a Secure Authentication Framework integrated with the Operating System (OS).
It enhances system security by implementing Multi-Factor Authentication (MFA), strong password policies, and protection against unauthorized access.
In simple terms, this project builds an advanced login security system that works at the OS level to protect the system from unauthorized users and potential threats.

Objectives

Prevent unauthorized access to the system
Provide a strong and reliable authentication mechanism
Ensure user data security
Improve overall system-level security

Features

Multi-Factor Authentication (MFA)
Combines password with OTP or biometric verification
Example: User logs in using password + OTP
Strong Password Policy
Minimum password length enforcement
Requires special characters and numbers
Password expiration feature

User Management
Add, remove, and update users
Role-based access control (Admin / User / Guest)
Security Alerts
Alerts for multiple failed login attempts
Detection of suspicious or unknown login activity

Dashboard Monitoring
Displays login activity logs
